# Kat Muis Zak Publiceren

Deze app is volledig statisch. Je kunt de inhoud van deze map uploaden naar vrijwel elke webhost.

## Bestanden die mee moeten

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `app-icon.svg`
- `sw.js`
- de volledige map `assets`

`server.mjs` en `start-webversie.cmd` zijn alleen handig voor lokaal testen en hoeven niet mee naar hosting.

## Makkelijke opties

1. Netlify Drop: sleep de map naar https://app.netlify.com/drop
2. GitHub Pages: zet de bestanden in een repository en activeer Pages
3. Vercel: importeer de map/repository als statische site
4. Eigen hosting: upload de bestanden via FTP of het beheerpaneel

Na publicatie krijg je een gewone URL die je naar derden kunt sturen.
